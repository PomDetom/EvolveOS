# 应用壳产品化 B3（设置完善）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 设置「外观」分区从「看起来只调字体」升级为「全局 UI 外观调整」——滑杆真正作用于整体（B2 玻璃落地后已自然生效）、分组重命名体现全局语义、加实时整体预览图。

**Architecture:** 复用现有定制器实现（`customizer-panel.js` GROUPS + 滑杆 + store 订阅双向同步）；B2 已让玻璃滑杆在应用壳内生效可见；本任务重命名分组标题（色彩→整体色调、玻璃材质→表面质感等）+ 外观分区顶部加实时整体预览（缩略展示当前主题/玻璃/圆角/图标效果，订阅 store 实时刷新）。

**Tech Stack:** Vite + 原生 JS + Vitest + Playwright（现有，零运行时依赖，测试仅 Web 环境）。

## Global Constraints

- 测试仅在 Web 环境执行（不跑 tauri dev）；动画红线（只动 transform/opacity，模糊永不动画，时长/曲线经 CSS 变量）；配置链路（defaults→store→apply，不绕过）。
- 零运行时依赖；组件无抽象封装；遵循现有代码风格（src/CLAUDE.md）。
- **视觉基线可能变**：外观分区新增整体预览图会改变 `app-main-*.png` / `components-partition-*.png` 渲染 → 重生成基线；确认差异由本次改动引起后 `--update-snapshots`。
- 每任务 TDD（先红后绿）、独立评审、修复循环（≤5 轮）；留痕入 `docs/superpowers/sdd/`。
- **每任务结束时 `npm test` + `npm run test:e2e` + `npm run test:visual` + `npm run build` 全绿**。
- docs 模式已删除（B1）；浏览器 `/` 直进应用壳；`?mode=strip` 保留。

test('外观分区顶部有实时整体预览卡', async ({ page }) => {
  await page.goto('/?mode=app');
  await page.locator('.c-titlebar__control--settings').click();
  await page.locator('.app-main__nav-r .c-navwheel__item').nth(1).click();
  const overview = page.locator('.cust-overview');
  await expect(overview).toBeVisible();
  // 切强调色 → 预览卡强调色同步变化
