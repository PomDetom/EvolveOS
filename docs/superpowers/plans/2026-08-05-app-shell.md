# 应用壳实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 按规格 2026-08-05-app-shell-ui-design.md 将项目主体转型为真实应用壳：双模式入口、NavigationWheel 参数化（黄金比例锚点 + 横竖方向）、双窗口级联、标题栏上下文、FloatStrip 悬浮条、手机底部横滑 + 页面栈。

**Architecture:** 单 index.html + `?mode=` 参数（浏览器默认 docs / Tauri 探测进 app / `?mode=strip` 悬浮条）；docs 渲染迁 `src/docs/docs-mode.js` 纯搬移；应用壳新建 `src/app/`；NavigationWheel 几何参数化（anchorRatio/direction）；FloatStrip 新组件；手机形态媒体查询切换。

**Tech Stack:** 现有 Vite + 原生 JS + Vitest + Playwright；Tauri 2 壳（已就绪，测试仅在 Web 执行）。

## Global Constraints

- **测试仅在 Web 环境执行**（不启动 tauri dev 验证；Tauri 壳可启动即视为环境就绪，桌面内页面行为由用户自行测试）— 根 CLAUDE.md 铁律。
- 零运行时依赖；动画红线（只动 transform/opacity + paint-only 豁免口径）；令牌引用；配置链路（defaults → store → apply）。
- docs 模式（浏览器 `/`）必须与当前展示页**逐字节等价** — 84 个既有 e2e 与 36 张基线（除导航轮相关 18 张）零冲击；docs 任何改动须核验不在 shot selector / 计数断言内。
- 每任务：计划/工作内容/提交留痕入 `docs/superpowers/sdd/`（账本 progress-app-shell.md），随代码提交；TDD 先红后绿；独立评审；模型分级（机械 haiku / 集成 sonnet / 审查 opus）。
- 视觉基线：导航轮相关 18 张重生成（选中锚点 38.2% 变化）+ 应用壳新增 6 张；其余 18 张零变化。
