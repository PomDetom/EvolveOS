# 应用壳产品化 B2（视觉主体）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 应用壳视觉主体升级——玻璃材质两档（磨砂/纯色不透明）、浏览器装饰背景层（模糊对象）、导航图标四项增强（提亮高对比/衬底/选中光晕分层/尺寸粗细分级）。

**Architecture:** 复用既有玻璃体系（`.glass` + `backdrop-filter` + `--glass-*` 变量）；配置新增 `glass.blurEnabled` 走完整链路（defaults→store→apply）；应用壳导航栏/内容区/卡片从纯色 `--surface-1` 切换为玻璃材质；浏览器侧 `.app-main` 根部加装饰背景层（3 预设，会话内切换，Tauri 透明）；图标增强作用于 NavigationWheel 组件 + 应用壳左右窗纯图标栏。

**Tech Stack:** Vite + 原生 JS + Vitest + Playwright（现有，零运行时依赖，测试仅 Web 环境）。

## Global Constraints

- 测试仅在 Web 环境执行（不跑 tauri dev）；动画红线（只动 transform/opacity，模糊永不动画，时长/曲线经 CSS 变量）；配置链路（defaults→store→apply，不绕过）。
- 零运行时依赖；组件无抽象封装；遵循现有代码风格（src/CLAUDE.md）。
- **视觉基线会变**：应用壳接玻璃 + 图标增强必然改变 `app-main-*.png` 与 `components-partition-*.png` 渲染 → 需重生成基线；确认差异由本次改动引起后 `--update-snapshots`。
- 每任务 TDD（先红后绿）、独立评审、修复循环（≤5 轮）；留痕入 `docs/superpowers/sdd/`。
- **每任务结束时 `npm test` + `npm run test:e2e` + `npm run test:visual` + `npm run build` 全绿**。
- docs 模式已删除（B1 完成）；浏览器 `/` 直进应用壳；`?mode=strip` 保留。
