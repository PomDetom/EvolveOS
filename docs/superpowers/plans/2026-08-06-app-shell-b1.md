# 应用壳产品化 B1（架构地基）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把「docs 设计系统展示页 + 应用壳」双形态收敛为「应用壳唯一产品形态」——浏览器 `/` 与 Tauri 直进应用壳，设计系统展示内容（组件/动效）内化为设置子菜单分区，窗口控制双通道，docs 渲染删除。

**Architecture:** 展示内容从独立 docs 页收进应用壳设置目录（10 分区，新增「组件」「动效」）；`mode.js` 简化为 app/strip 两态；`docs-mode.js` 与 docs 专属 CSS 删除；窗口控制桥加浏览器降级通道（按钮保留 + toast）。任务排序为「先加后删」：分区内化 → 窗口降级 → 测试迁移 → 模式切换/删除，保证每任务结束时全量回归绿。

**Tech Stack:** Vite + 原生 JS + Vitest + Playwright（现有，零运行时依赖，测试仅 Web 环境）。

## Global Constraints

- 测试仅在 Web 环境执行（不跑 tauri dev）。
- 动画红线：只动 transform/opacity，模糊永不动画，时长/曲线经 CSS 变量。
- 配置链路：defaults → store → apply，不绕过直接写 CSS 变量。
- 每任务 TDD（先红后绿）、独立评审、修复循环（≤5 轮）；留痕入 `docs/superpowers/sdd/`。
- docs 展示页删除后，docs 专属 e2e 与视觉基线随之迁移/删除；**每任务结束时 `npm test` + `npm run test:e2e` + `npm run test:visual` + `npm run build` 全绿**。
- 零运行时依赖；组件无抽象封装；遵循现有代码风格（src/CLAUDE.md）。

export function resolveMode(params, hasTauri) {
