# 应用壳 UI 设计规格

- **日期**: 2026-08-05
- **状态**: 已确认（brainstorming 完成，待执行）
- **前置**: 设计规格 2026-08-04-tauri-ui-design.md（设计系统基础）；实施计划 2026-08-05-iteration.md（迭代期，已并入 main）

## 1. 背景与目标

项目主体从「设计系统展示页」转型为**真实应用壳**（通用壳，模块占位，后续逐个填充剪贴板/密码/记账等小应用）。展示页降级为开发文档模式（`?mode=docs`）。本规格定义应用壳的完整 UI 设计，核心设计语言不变（滑动选择导航、克制玻璃、灵动弹性、黄金比例锚点）。

用户确认的四个核心构想：
1. **级联双滑动窗口**：左栏恒为应用列表，点击应用/设置 → 右栏展开其目录
2. **纯图标导航**：滑动窗口只显示 icon（双窗各 64px），名称由标题栏上下文承担
3. **标题栏重构**：不承载任何导航；设置按钮移入标题栏；显示「应用名 › 页面名」上下文
4. **黄金比例锚点**：滑动窗口选中项锚在视口 38.2%（上三分线），替代居中

## 2. 整体架构

```
┌────────────────────────────────────────────────────────┐
│ 标题栏 40px：拖拽区（「应用名 › 页面名」上下文）  [⚙设置] [— □ ×] │
├──────┬──────┬──────────────────────────────────────────┤
│ 左窗  │ 右窗  │ 内容区                                    │
│ 64px  │ 64px  │ （右窗选中项对应的页面）                     │
│ 应用列表 │ 应用内目录 │  单窗口态：内容区 = 左窗选中应用首屏      │
│ 纯icon│ 纯icon│  双窗口态：右窗驱动内容区                    │
└──────┴──────┴──────────────────────────────────────────┘
```

- **双窗口级联**：同一 NavigationWheel 组件两实例；左窗选中驱动右窗内容，右窗选中驱动内容区
- **左栏恒定** = 应用列表（概览/剪贴板/密码/记账/搜索/帮助/关于 7 项）；设置不是左栏项
- **模式即右窗内容**：右窗 = 应用内目录 或 设置目录（8 分区：通用/外观/界面/快捷键/通知/数据/高级/关于），共用级联机制
- **黄金比例锚点**：`anchorRatio = 0.382`（替代 50% 中心），左右窗一致；focal 变形峰值/光晕/首尾 padding 同步参数化

## 3. 标题栏

- 左侧大拖拽区：唯一内容 = 当前上下文指示（「应用名 › 页面名」；设置模式「设置 › 外观」；单窗口态「应用名」），随导航实时联动
- 设置按钮（⚙）在右侧窗口控制旁；设置模式时高亮激活态
- 窗口控制（— □ ×）保持 Tauri 桥接（既有 bindWindowControls）
- 无任何导航元素、无品牌字（品牌字挪到「关于」页）

## 4. 滑动窗口（NavigationWheel 参数化）

- **几何参数化**：`anchorRatio`（默认 0.382）+ `direction: 'vertical' | 'horizontal'` — scrollTopForAnchor、findNearestIndex、focal 变形峰值、光晕、首尾 padding 统一沿主轴参数化（geometry 纯函数可单测）
- **左窗**：7 项（64px 高 + 12px 间距 = 532px > 视口可真实滑动），纯 icon，选中高亮 + 光晕；名称不占栏宽
- **右窗**：默认隐藏（单窗口态）；点击左窗应用 → 弹性推入（translateX + fade，`--ease-spring`，只动 transform/opacity）载入应用目录；再点其他应用 → 内容平滑切换（不收起）；点击 ⚙ → 右窗切换为设置目录
- **右窗收起三通道**：右窗顶部小返回按钮（chevron-left）/ 再次点击左窗已选中项 / Esc
- **动画**：右窗推入/收起 240ms + `--ease-spring`；选中锚点变化 `--dur-base` 弹性（目标点 38.2%）

## 5. 悬浮条 FloatStrip（新组件体系）

- **双形态**：横条（内容横向）/ 竖条（内容纵向），同一内容区自适应旋转
- **四边磁吸**：拖动距屏幕边缘 < 24px 自动吸附；横条常态贴左右，竖条常态贴上下
- **无边框内容优先**：常态零边框零标题栏；hover 浮现半透明细边框 + 迷你控制条（旋转/拖动/关闭）
- **旋转切换**：控制条按钮 + 双击内容区（双通道）
- **独立运行**：Tauri 独立透明窗口（alwaysOnTop + skipTaskbar + `?mode=strip` 入口）；应用壳内模拟演示（右下贴边可拖）
- **内容模板**：token 监测示例（数值 + 状态点 + 迷你趋势条，供后续应用复用）
- 既有 FloatingWindow 保留（悬浮窗场景模板用），FloatStrip 为新增组件

## 6. 内容区与页面

- 右窗选中项驱动唯一 active 页（切页 120ms fade + translateY 4px）；单窗口态由左窗驱动（应用首屏）
- **应用占位页骨架**：统一 EmptyState（图标 + 「功能开发中」+ 「接入 X 后替换此处」）+ 页面头（应用名）
- **概览页**（默认首屏）：欢迎卡 + 应用快捷入口卡片（点击 = 展开右窗 + 切到该应用）+ 主题状态卡
- **设置页**：沿用现有 settings-window 实现（8 分区 + 外观定制器整页 + HotkeyRecorder + 主题三态）— 共享实现，行为不变
- 模式状态机：单窗口态 / 双窗口态（应用目录 / 设置目录）— 右窗状态为纯 UI 态（会话内），不进配置存储

## 7. 手机形态（≤900px，仅手机场景）

- **底部横滑应用栏**：icon 横排左右滑动，黄金比例锚点横向化（NavigationWheel horizontal + anchorRatio）
- **全屏页面栈**：点击应用 → 目录页推入（slide 左进右出）→ 点击目录项 → 详情页推入；返回按钮/边缘右滑逐步回退
- 上下滑动逻辑全部横向化；设置从标题栏 ⚙ 进入（设置页推入）
- 桌面级联双窗与手机页面栈两套导航模型，媒体查询切换

## 8. 模式与入口

- 浏览器 `/` → docs 展示页（现状等价 + topbar「应用壳」链接）
- Tauri 桌面（无 query）→ 应用壳（探测 `window.__TAURI__`，与既有 bindWindowControls 同模式）
- 显式 `?mode=app` / `?mode=docs` 覆盖探测；`?mode=strip` 为悬浮条独立入口（Tauri 独立窗口）
- docs 模式渲染迁 `src/docs/docs-mode.js`（纯搬移）；app 走动态 import（Vite 自动分包，docs 默认路径零额外加载）

## 9. 技术影响与测试

| 变更 | 范围 |
|---|---|
| NavigationWheel 几何参数化 | anchorRatio + direction；geometry 单测适配 + 新增用例；**视觉基线 18 张导航轮相关重生成** |
| FloatStrip 组件 | 新组件（形态/磁吸/无边框/旋转）+ 模拟演示 + 独立入口说明 |
| 手机页面栈 | slide 推入/回退（只动 transform/opacity）+ 返回手势；viewport 窄屏测试 |
| 应用壳结构 | 双窗口级联 + 标题栏上下文；窄屏手机形态 |
| 测试 | 新 spec：app-shell（级联/收起/设置目录）、floatstrip（旋转/磁吸/无边框）、mobile-nav（横滑/页面栈）；既有 nav-wheel/场景 spec 适配锚点；基线 +6 张（应用壳）+ 18 张重生成 |

## 10. 验证

- 每任务：`npm test` + `npm run test:e2e` + `npm run build` 全绿
- 视觉：基线重生成范围 = 18 张导航轮相关 + 新增 6 张应用壳；其余零变化
- 手工：浏览器 `?mode=app` / `/` / `?mode=strip`；手机形态 viewport 模拟；Tauri 桌面由用户目检

## 11. 非目标（本期不做）

- 应用真实功能填充（剪贴板/密码/记账仅占位页）
- Tauri 悬浮条独立窗口的 Rust 侧实现（`?mode=strip` 入口 + 接入指南说明，真实独立窗口由应用接入）
- 手机端原生手势（边缘右滑用简单按钮 + 可选 touch 事件）
- 多级联第三窗口（应用内深层级后续按需）
