# Tauri 统一 UI 设计系统 — 设计规格

- **日期**: 2026-08-04
- **状态**: 已确认（brainstorming 完成，待实施计划）
- **技术形态**: 方案 A — 纯原生 Web（Vite + HTML/CSS/JS，零框架依赖）

## 1. 背景与目标

为作者的多个 Rust Tauri 桌面应用（剪贴板、密码管理、记账等）建立统一的设计语言与 UI 风格。本项目产出一个完整的**设计系统展示页**，作为所有应用的设计基准，同时提供可在应用中复用的设计令牌与原生组件。

核心诉求：
- **一体式 UI**：无边框透明窗口，上下无割裂
- **滑动选择**作为整体设计语言：左侧滑动导航 + 设置页滑动分区
- **动画流畅优美**：灵动带弹性（轻微回弹，克制不油腻）
- **风格简洁**：克制的玻璃质感
- **可配置**：所有界面效果有可视化自定义入口（主题定制器）
- **多平台**：Windows / macOS / Linux，跨平台表现一致

## 2. 已确认的需求决策

| 维度 | 决策 |
|---|---|
| 技术形态 | 方案 A：Vite + 原生 HTML/CSS/JS，零框架、零依赖、零抽象 |
| 应用形态 | 全覆盖：常驻小组件 / 呼出面板 / 完整主窗口 |
| 视觉质感 | 克制的玻璃质感：窗口内半透明层 + 柔和高光 + 细边框，**不依赖系统级背景模糊**（macOS vibrancy / Windows 插件均不做），保证跨平台一致 |
| 主题 | 深/浅双主题，三态（跟随系统 / 深 / 浅），手动切换记忆偏好 |
| 交付物 | 设计系统展示页 + 3 个场景模板（剪贴板悬浮窗 / 主窗口 / 设置页） |
| 动效性格 | 灵动带弹性：关键动画轻微 overshoot（≈10-12%），装饰过渡柔和 |
| 交互方式 | 滚轮/触摸板滑动 + 鼠标拖拽（带惯性） |
| 导航名称 | 选中项才显示名称，未选中仅图标（clip-path 滑入式显现） |
| 设置入口 | 导航栏左下角固定，设置页分区同样用滑动选择 |
| 主题色 | **6 套风格预设**（靛蓝/青绿/天蓝/琥珀/紫罗兰/翡翠），展示页一键切换预览，最终方案后期确定；每套含深浅主题变体 |

## 3. 设计原则

1. **华丽动画，简洁视觉** — 视觉元素克制（无框无格、少色少线），动画是唯一的表情来源
2. **滑动选择即语言** — 导航、设置分区、选择类交互统一为「滚动 → 居中吸附 → 选中放大」的交互模式
3. **玻璃材质是材质，不是装饰** — 半透明 + 高光 + 细边框模拟玻璃，用于外壳层级（窗口、面板、浮层），内容层保持高可读性
4. **性能红线** — 动画只用 `transform` + `opacity`（GPU 合成）；模糊值永不动画；超过 6 项同时动画必须 stagger
5. **框架无关，复制即用** — 组件是「结构化 HTML + CSS 类 + 渐进增强 JS」，任何 Tauri 应用可直接引用
6. **一切可调** — 所有设计参数走 CSS 变量，全部可由主题定制器覆盖

## 4. 项目架构

```
ui-design/
├── index.html                # 展示页入口（单页）
├── src/
│   ├── styles/
│   │   ├── tokens.css        # 设计令牌默认值（唯一事实源）
│   │   ├── themes.css        # 深/浅主题变量映射
│   │   ├── motion.css        # 动效参数（时长/缓动/弹性）
│   │   └── base.css          # 重置、字体、全局规则
│   ├── config/               # 可配置层
│   │   ├── defaults.js       # 每项参数的默认值 + 取值范围定义
│   │   ├── store.js          # 读取/保存配置（localStorage + 深合并默认值）
│   │   └── apply.js          # 配置 → CSS 变量覆盖层（实时生效）
│   ├── components/           # 原生组件（HTML 结构 + CSS + 渐进增强 JS）
│   ├── scenes/               # 3 个场景模板
│   ├── demo/                 # 展示页专用交互（主题切换、动效实验室、定制器）
│   └── main.js
├── tests/                    # Vitest 单元测试 + Playwright 交互/视觉回归
└── package.json
```

**关键决策**：
- 组件不做 Web Components 封装，保持零抽象，从应用中直接复制使用
- 主题用 `data-theme` 属性挂在 `<html>` 上；`tokens.css` 定义语义令牌，`themes.css` 做亮/暗映射
- CSS 变量双层结构：默认值（tokens.css）→ 覆盖层（apply.js 写入的 inline CSS 变量），定制器实时预览即覆盖层生效
- 展示页是纯静态 Web 页面，同时可直接放进 Tauri 窗口运行

## 5. 设计令牌体系

### 5.1 色彩：6 套主题色风格预设

**中性色阶**：12 级冷调灰。亮色 100→900 从 #f7f8fa 到 #1a1d23；暗色主题反转（色板两套）。

**主题色风格**（6 套，展示页顶部一键切换预览，最终主色由切换对比后确定）——每套定义主色在深浅主题下的变体（浅主题用偏深强调色保证对比度，深主题用偏亮强调色）与语义色微调：

| 风格 | 基准主色 | 气质 | 适合场景 |
|---|---|---|---|
| 靛蓝 Indigo（默认） | #6e7bf2 | 冷静、专业 | 工具类、办公（默认推荐） |
| 青绿 Teal | #2dd4bf | 清爽、科技 | 悬浮窗、效率工具 |
| 天蓝 Sky | #38bdf8 | 明朗、开放 | 数据、信息类 |
| 琥珀 Amber | #f59e0b | 活力、温暖 | 创作、生活记录 |
| 紫罗兰 Violet | #a78bfa | 优雅、个性 | 创意、年轻化 |
| 翡翠 Emerald | #34d399 | 自然、治愈 | 记账、健康 |

- 每套风格 = 主色 + 深浅主题变体 + 语义色微调（成功/警告/危险/信息保持可识别，色相跟随风格微调）
- 语义色基准：成功（绿）/ 警告（琥珀）/ 危险（红）/ 信息（蓝），各带 8 级色阶
- **透明度变体**：每个色阶含 3 档透明度变体（10% / 25% / 40%），玻璃层专用
- 实现：`[data-accent="indigo|teal|sky|amber|violet|emerald"]` 属性选择器组织各套色板，与 `data-theme` 正交组合；展示页切换只换属性，全局生效

### 5.2 玻璃材质参数（深浅主题各自定义）

| 参数 | 亮色 | 暗色 |
|---|---|---|
| 表面透明度 | 72-85% | 60-75% |
| 背景模糊 | 20px | 28px |
| 高光边框（内 top 边） | rgba(255,255,255,0.5) | rgba(255,255,255,0.08) |
| 阴影 | 3 级浮层阴影 | 3 级浮层阴影 + 更深的投影 |

玻璃材质的哲学：**暗色下玻璃更通透（低透明度、强模糊），亮色下玻璃更实（高透明度、弱模糊）**，两主题下质感都成立。

### 5.3 字体 / 间距 / 圆角 / 阴影 / Z 层级

- **字体**：系统栈 `-apple-system, "Segoe UI", "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif`；等宽 `"JetBrains Mono", "Cascadia Code", Consolas, monospace`；字号阶梯 10→28px（7 级）；字重 400/500/600/700；行高 1.4-1.6
- **间距**：4px 基准标尺 4/8/12/16/24/32/48
- **圆角**：xs 6 / sm 8 / md 12 / lg 16 / xl 20 / full；悬浮窗外壳用 xl-lg，主窗口 sm-md
- **阴影**：3 级浮层阴影 + 1 内高光（玻璃边框感）
- **Z 层级**：基础 1 / 悬浮 10 / 浮层 20 / 弹窗 30 / 提示 40

### 5.4 动效令牌

| 令牌 | 默认值 | 用途 |
|---|---|---|
| `--dur-fast` | 120ms | 悬浮窗呼出收起、hover 反馈 |
| `--dur-base` | 200ms | 面板开合、列表滑入 |
| `--dur-slow` | 300ms | 主题切换渐变、大面板过渡 |
| `--ease-out` | 标准减速曲线 | 装饰过渡 |
| `--ease-spring` | 弹性曲线（overshoot ≈ 10-12%，单次回弹） | 呼出、开关、徽标弹出 — 设计个性所在 |
| `--spring-strength` | 0.6（0-1） | 弹性强度，定制器可调到 0 = 无回弹 |

## 6. 主题定制器（可配置层）

所有界面效果的可视化自定义入口，内嵌于展示页（可折叠面板），同时可整页嵌入（见设置页场景模板）。

**分组**（每组滑杆/选择器/开关，调整实时生效）：
- 色彩：**主题色风格卡片**（6 套预设，名称 + 主色圆点 + 气质描述，点击整组切换）→ 风格之上可继续微调（色相/饱和/明度三轴、中性色温冷↔暖、语义色微调）
- 玻璃材质：表面透明度、背景模糊强度、高光强度
- 排版：基准字号、字号缩放比、字重偏好
- 圆角：全局圆角滑杆（xs→xl 整体缩放）
- 动效：时长缩放、弹性强度（0 = 无回弹）、动效总开关
- 阴影：强度滑杆

**预设管理**：内置「默认深/浅」+「6 套主题色风格」+「保存我的方案」（localStorage）+「导出 CSS 变量代码」（复制到剪贴板，粘入 Tauri 应用即得一套完整主题）+「重置」。

**实现**：defaults.js 定义每项默认值与取值范围；store.js 负责读取/持久化（防抖 300ms、深合并、损坏兜底）；apply.js 将配置写入 CSS 变量覆盖层。动效参数经 CSS 变量注入，弹性强度映射为 spring 近似曲线（可用 CSS `linear()` 实现）。

**复用价值**：每个 Tauri 应用可嵌入同一套定制器 + 配置存储，让最终用户自定义界面。

## 7. 组件清单（32 个，分 6 组）

| 组 | 组件 |
|---|---|
| **核心导航** | **NavigationWheel**（滑动选择导航，规格见 §8）、**TitleBar**（一体式自绘标题栏，规格见 §9）、SidebarItem |
| **基础表单** | Button（4 变体 × 3 尺寸）、Icon（内联 SVG 圆润线性图标集）、Input、Textarea、Select、Checkbox、Radio、Switch、Slider、Kbd |
| **数据展示** | Card、List（可选项/多行项）、Badge、Tag、Progress、Avatar、Skeleton、EmptyState |

| **悬浮窗专属** | FloatingWindow（外壳：透明圆角、高光边框、DragRegion、ResizeHandle、置顶/折叠）、SearchBar（含命令提示）、HotkeyHint、FloatBall（悬浮球触发体）、HotkeyRecorder（设置页用） |

每个组件 = 结构化 HTML + CSS 类 + 渐进增强 JS，支持全部变体展示。

## 8. NavigationWheel（核心组件）规格

**布局**：竖向列表，每项 = 28px 圆润线性 icon + 名称区；导航栏宽 176px；顶部/底部渐变遮罩提示可滚动；无框无格。

**名称显示**：未选中项名称区 `clip-path` 收缩为 0（视觉零宽，不触发布局）；选中项名称从 icon 右侧滑入显现 + 轻微位移（120ms + 弹性）。

**滚动机制（JS 驱动，GPU 合成）**：
1. 滚轮/触摸板 → 原生滚动；鼠标拖拽 → pointer 事件 + 动量惯性（衰减）
2. **实时跟手变形**：requestAnimationFrame 按每项到视口中心距离实时计算 `scale`/`opacity`/`y` — 中心项 scale 1.15 + 高光点亮，相邻项依次缩小淡出（focal carousel 效果）
3. 松手/滚动停止 → 最近模块**居中吸附**并选中
4. 点击某项 → 平滑滚动将其带到中央（点击后滑动到中间）
5. 选中项身后一道低透明度径向光晕跟随（华丽来源，克制呈现）

**切换动画**：旧项收缩、新项放大（弹性 200ms）、名称滑入。键盘方向键支持（无障碍保底）；`prefers-reduced-motion` 降级为直接居中无动画。

**设置入口**：导航栏底部 sticky 固定设置 icon + 细分隔线，同一视觉语言。

**通用化**：NavigationWheel 提供横/竖两种变体，设置页分区切换使用，与主导航呼应。

## 9. TitleBar（一体式标题栏）规格

- 高 36-40px，与内容共享玻璃材质 — 无边框无分隔割裂感
- 左侧拖拽区（可放应用名/logo），右侧窗口控制按钮（最小化/最大化/关闭，玻璃按钮 + hover 高亮）
- Tauri 接入要点：`decorations: false` + 透明窗口；拖拽用 `data-tauri-drag-region`；窗口控制走 Tauri 窗口 API；macOS traffic lights 处理建议写入接入指南

## 10. 展示页结构（自证设计语言）

- **顶部栏**：Logo、分区快捷跳转、**主题色风格切换**（6 套预设一键对比）、深/浅/跟随切换、定制器入口
- **侧边导航**：直接用 NavigationWheel 实现 — 浏览设计系统本身就是在体验滑动选择
- **内容区**（1200px 内留白，玻璃质感靠留白呼吸）：
  - 设计令牌：色彩（色板卡，点击复制 CSS 值）、字体阶梯、间距/圆角/阴影标尺、玻璃材质即时预览
  - 组件区：6 组 32 组件，变体 + 参数说明
  - 动效实验室：每个动效的时长/弹性/位移试玩器，与定制器联动
  - 场景模板：3 个完整页面
- 窄屏自动折叠导航为顶部下拉

## 11. 场景模板（3 个）

### 11.1 剪贴板悬浮窗（验证悬浮窗场景）
- ~360×480 圆角透明小窗，FloatingWindow 外壳（拖拽区、高光边框）
- 顶部：SearchBar（搜索历史，含空态）+ 置顶/折叠控制
- 列表：stagger 滑入；悬停行显示操作（复制/固定/删除）；HotkeyHint 角标
- 底部：固定项分区 + 「清空全部」（Dialog 危险确认）
- 诚实边界：浏览器内用「模拟悬浮窗」（position: fixed 可拖拽缩放，复刻布局交互）演示；附 Tauri 接入指南（透明窗口配置、DragRegion 映射、置顶 API）

### 11.2 主窗口（一体式 + 滑动导航组合）
- 一体式 TitleBar + 左侧 NavigationWheel + 内容区
- 5 个模块占位页，各用一种内容形态：仪表盘卡片 / 数据列表 / 表单 / 图片网格 / 空态

### 11.3 设置页（滑动选择分区 + 定制器整页嵌入）
- 一体式 TitleBar + 分区滑动选择（NavigationWheel 变体）
- 分区：通用（主题三态、动效开关、启动行为）/ 外观（主题定制器整页形态）/ 快捷键（热键列表 + HotkeyRecorder）/ 关于

## 12. 数据流

```
用户交互（滑动/点击/滑杆/主题切换）
      ↓
config/store.js（唯一状态源，内存态）
      ↓                        ↓
localStorage 持久化         apply.js 写入 CSS 变量覆盖层
（防抖 300ms，深合并默认值）       ↓
                       所有组件/场景实时响应
```

- 主题三态用 `matchMedia('(prefers-color-scheme: dark)')` 监听系统切换
- NavigationWheel 选中态是纯 UI 态，不进配置存储
- 无状态管理库、无网络请求、零依赖

## 13. 错误处理

| 场景 | 处理 |
|---|---|
| localStorage 不可用（隐私模式） | 配置会话内生效，一次性提示条 |
| 配置 JSON 损坏 | 深合并默认值兜底，静默修复 |
| SVG/资源加载失败 | 组件内联 SVG，天然零失败面；图片处有占位色块 |
| 无 JS 环境 | 渐进增强：内容仍渲染，导航锚点可跳 |
| reduced-motion | 全局降级 0ms 瞬切 + 无动画居中 |

## 14. 测试

- **Vitest 单元测试**：store 合并/持久化/兜底；apply.js 配置→CSS 变量映射；NavigationWheel 吸附算法（纯函数提取）
- **Playwright 交互测试**：主题切换、定制器滑杆实时生效、滑动导航点击居中吸附、拖拽惯性
- **Playwright 视觉回归**：深浅主题下全部组件 + 3 场景模板截图对比
- **人工验收**：动效流畅度（帧率感受）与审美判断 — 展示页附动效演示区供逐个审视

## 15. 非目标（YAGNI）

- 不做后端、不做网络请求、不做账号体系
- 不做 Web Components 封装、不发布 npm 包（将来如需组件库，从令牌层封装顺路）
- 不做系统级桌面背景模糊（真毛玻璃）与平台私有特效
- 不做状态管理库、不引入任何框架依赖
- 不实现真实 Tauri 窗口 API（接入指南 + 模拟演示，真实窗口由各应用接入）

## 16. 后续演进（不在本期范围）

- 从令牌层出发封装 Svelte/Vue 组件库的路径
- 图标集扩充与自动生成
